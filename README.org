#+title: kaoyan-math-official-resources

本仓库用于从历年的考试大纲中收集考研数学的真题。

1987—1990年的真题目前来自《历年考研数学真题解析及复习思路》（数学一至数学四各册），扫描件见 [[file:真题来源存档/][真题来源存档]]。

目前的试卷排版我随便排的，它也不具备什么现实依据。一个可能的方案是靠每年的考生回忆试卷尺寸，字体，间距什么的。如果你恰巧已经毕业了，你可以尝试报名考研来并在考场上尝试测量和记忆各种参数啥的。
