该 PDF 包含概率论与数理统计：第三部分从 PDF 第 311 页（书内第 306 页）开始，标题注明“数学二不要求”。文件名及扉页中的适用范围不表示扫描正文没有概率论。

按学科、章节录入原书“考试内容解析”部分，到“例题详解”之前为止，不含各章例题及其解答。每章一个独立 Org 文件。原书勘误集中记录于 [[file:原书勘误.org][原书勘误]]。

* 格式

每章声明 =#+TYPST_MATH: t=，采用 org-typst-math。正文及标题使用 Org 语法；行内公式使用 =$…$=，独立公式使用独占一行的 =$$= 分隔符，分隔符内部使用 Typst 数学语法。源文件不含页面、字体等版式设置。
