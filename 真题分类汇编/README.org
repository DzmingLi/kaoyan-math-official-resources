#+title: 历年真题分类汇编

* 收录范围

仅从仓库现有历年真题筛选，不收录样卷或大纲章节例题. 分类汇编仅收录至2020年，2021—2026年的真题不纳入. 同题合并真题题号，题号与题干同行显示，各份源文件保持自包含.

题目使用ezexam.question，解析使用ezexam.solution；经构建时生成的preview入口采用A4排版，不生成小册子版. 每个顶层专题文件夹对应一个Release，分别提供题目和解析PDF. 原书勘误保存在各专题的独立Org文件中.
